# Song Requests

Live song-request app for pub gigs. Audiences scan a QR code, browse the setlist and request songs; the musician runs everything from the PIN-protected stage view.

Live site: https://musicianstools.github.io/Requestasong/

Deployed automatically by GitHub Actions on every push to `main` (Settings → Pages → Source must be "GitHub Actions"). Data lives in Firebase Firestore. See FEATURES.md for the feature list.
